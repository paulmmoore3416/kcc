# Kraken Cloud Control (KCC) - Project Instructions

## Development Workflow
- **AI Provider**: Default to `ollama` with `qwen2.5:latest` for sovereign autonomy.
- **FinOps**: Ensure FOCUS compliance for all new cost modules.
- **DePIN**: Prioritize Arbitrage and QA Benchmarking for all new provider integrations.

## Security
- Do not commit Personal Access Tokens (PATs) or API keys to the repository.
- Use the local environment variables or private memory for sensitive credentials.
